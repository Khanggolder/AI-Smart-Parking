## 1. Mục tiêu

- Bổ sung cấu hình `.env.example`.
- Không đưa dữ liệu lớn hoặc thông tin bảo mật vào repository.

## 2. Git Workflow

Repository đã có tài liệu `CONTRIBUTING.md`, hướng dẫn thành viên:

1. Tạo Issue cho công việc.
2. Làm việc trên nhánh tính năng.
3. Commit thay đổi với nội dung rõ ràng.
4. Push lên GitHub.
5. Tạo Pull Request vào `main` và yêu cầu review trước khi merge.

Nhánh Frontend: `feature/frontend-khoi`.

Issues liên quan:
- Issue #3: https://github.com/Khanggolder/AI-Smart-Parking/issues/3
- Issue #6: https://github.com/Khanggolder/AI-Smart-Parking/issues/6

## 3. Frontend CI

File: `.github/workflows/frontend-ci.yml`

CI sử dụng GitHub Actions với Node.js 22 để chạy:

- `npm ci`
- `npm run lint`
- `npm run build`

Workflow được cấu hình chạy khi push lên `main`, `feature/frontend-khoi`, khi mở/cập nhật Pull Request hướng tới `main`, hoặc khi chạy thủ công.

**Kết quả kiểm thử:** Chờ xác nhận từ GitHub Actions.

## 4. Environment

Đã bổ sung `frontend/.env.example` với `VITE_API_BASE_URL`.

File chỉ chứa giá trị mẫu, không chứa mật khẩu hoặc token.

File `.env.example` tại thư mục gốc được giữ nguyên để các thành viên Backend và AI quản lý. Cần thống nhất ngưỡng AI giữa cấu hình mẫu và bản release khi thực hiện tích hợp.
